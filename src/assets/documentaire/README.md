# Images de l'accueil « Le documentaire »

Provenance de chaque image de ce dossier.

- `capsule-ecoute.jpg` et `capsule-sourire.jpg` : deux captures d'écran
  envoyées par Lilian le 14 octobre 2026, tirées de l'épisode #125 de Radio
  Contournement (enregistré à La Capsule, le studio qu'il a cofondé, publié le
  4 avril 2024). Chaque capture montrait l'écran partagé de l'émission ;
  seule la moitié droite, où Lilian est assis (casquette, t-shirt blanc), est
  gardée (recadrage ffmpeg `crop=880:997:892:0`). L'autre personne n'apparaît
  pas. La légende de la page cite l'émission.

Les autres photos de Lilian viennent de `src/assets/` : `lilian-au-bureau.jpg`
(son bureau) et `lilian-photo.jpg` (portrait). Les images de
`src/assets/work-scenes/` sont générées et ne le montrent pas : elles ne vont
pas sur l'accueil.
